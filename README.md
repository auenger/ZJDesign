# 琢匠 · 小人装配工坊

金属磁吸小人的 3D 在线装配原型。当前角色由程序化几何生成，用于验证交互、比例与视觉方向，不是参考照片中的实物模型复刻。

## Cloudflare Pages

连接 GitHub 仓库 `auenger/ZJDesign`，使用下面的构建设置：

| 配置 | 值 |
| --- | --- |
| 生产分支 | `main` |
| 框架预设 | `Vite`，或 `None` |
| 根目录 | 仓库根目录，无需填写子目录 |
| 构建命令 | `npm run build` |
| 输出目录 | `dist` |
| Node.js | `22`，仓库已提供 `.nvmrc` |

无需服务器、数据库或运行时环境变量。构建后全部内容为静态文件，3D 渲染和作品保存均在访客浏览器中完成。Cloudflare Pages 会自动安装依赖；请保留仓库中的 `package-lock.json`。

官方说明：[构建设置](https://developers.cloudflare.com/pages/configuration/build-configuration/)、[构建环境](https://developers.cloudflare.com/pages/configuration/build-image/)。

## 本地运行

```bash
npm install
npm run dev
```

打开终端输出的本地地址。生产构建使用 `npm run build`。

## 已实现

- 八个可独立替换的部位：头部、身体、手臂、腿部、头饰、护甲、武器、盾牌。
- 北境、东方武将、骑士三套造型，可跨系列组合；可移除头饰和装备。
- 北境套装参照实物拆件图细化：鼻梁护盔、断角、分层胡须、肌肉胸甲、铜色斜带、鳞甲裙、兽毛肩甲、腰间挂件、雕纹战斧及符文盾；背面也有兽毛、皮包和装备固定带。
- 真实 WebGL 3D 渲染、拖动旋转、滚轮或双指缩放、点击模型选择部位。
- 点击装配、电脑拖拽装配、吸附过渡、可选音效、拆解视图、自动旋转。
- 古铜、白银、黑铁材质，随机搭配，撤销、重做，作品命名。
- 当前浏览器保存最近 12 件作品、重新载入、删除和 PNG 导出。
- 实物参考图鉴和手机布局。
- 亮色、暗色和跟随系统主题，记住当前浏览器中的选择；3D 底座与导出图片同步适配主题。

## 资源占用

静止时停止 3D 帧渲染，旋转、装配和拆解时恢复；页面进入后台时暂停。阴影分辨率限制为 1024，渲染像素比上限 1.5，部件缩略图生成后释放临时 WebGL 上下文。图标仅保留使用到的 CSS 和 WOFF2 字体，不包含多余的 SVG/TTF/WOFF 字体文件。原始设计参考图保留在本机，仓库只携带站点使用的图片。

北境细节模型按部件和材质合并网格，整套控制在 18 万三角形、56 个网格以内；细小雕纹不会各自增加绘制调用。表面划痕、凹痕和粗糙度共用三张运行时生成的 256×256 纹理，无需额外下载大型贴图。

## 验证

先启动开发服务，再执行 `node tests/smoke.mjs`。测试使用 macOS 已安装的 Chrome；其他环境需安装 Playwright Chromium。可通过 `PREVIEW_URL` 指定预览地址。

开发服务运行时可执行 `node tests/model-details.mjs`，检查细节模型的几何数据、部位选择标识及网格预算；该项通过 Vite 源码入口运行，可用 `MODEL_TEST_URL` 指定开发服务地址。

## 模型接入

部件目录、槽位锚点、拆解偏移和基础程序化造型位于 `src/parts.js`，北境细节造型位于 `src/viking.js`。界面和场景位于 `src/main.js`。

正式模型建议按部件导出 GLB，统一比例和朝向；部件原点放在磁吸连接中心。头、身体、左/右臂、左/右腿、头饰、肩甲、武器和盾牌应单独建模，支持法线、粗糙度、金属度和包浆贴图。当前原型将左右手臂和左右腿分别作为成对部件处理，可在下一版拆分为独立槽位。

当前无账号、后台、商品价格或磁吸接口兼容性规则；保存仅在当前浏览器中生效。

## 乐高人偶模型实验室

首页右上角「模型实验室」进入 `/model-lab.html`。此页载入真正的外部 Blender 模型转换而成的 GLB，独立于原有程序化装配台。可比较两档细分精度，切换塑料/金属材质、三角线框，旋转缩放、拆解十个部件，并导出带署名的图片。它是模型查看实验，暂不参与主装配台的跨系列换装或作品保存。

模型：[LEGO Minifigure - Cycles](https://rioforce.wordpress.com/2013/07/30/download-a-lego-minifigure/)，作者 Rioforce。原作提供源文件和 CC BY 3.0 许可，但下载包同时明确标记 Fan Art、禁止商业使用，因此仅作为非商业技术测试素材，不能直接用于正式商业商品配置器。原始许可及修改说明保存在 `public/models/rioforce/`；公开的免费素材不等同于无限制商用素材。

| 版本 | 三角面 | GLB 大小（含原始贴图） |
| --- | ---: | ---: |
| 高精细（细分 2） | 263,376 | 907,040 字节 |
| 轻量版（细分 1） | 65,844 | 365,048 字节 |

模型和 Draco 解码器在本地静态目录托管，运行时不请求作者网站。只有打开实验页才加载模型，另一档精度按需下载并复用缓存。解码器 WASM 与封装脚本合计约 245 KiB，保留 Apache 2.0 许可；静止时暂停渲染，DPR 上限 1.5、阴影 1024。

重建资产：下载作者博客直接链接的 ZIP 并解压，在本机 Blender 4.2 中运行（网站构建不需要 Blender）：

```bash
blender --background --factory-startup --python scripts/convert-minifigure.py -- /path/to/extracted/source public/models/rioforce
```

转换脚本禁用源文件脚本执行，使用骨架静止姿态，按物理结构合并内部网格，保留 UV 和印花，转换旧版 Cycles 材质为 PBR，并进行 Draco 压缩。`manifest.json` 记录实际面数、文件体积和 SHA-256。

运行开发服务或生产预览服务后，执行 `node tests/model-lab.mjs`；可通过 `PREVIEW_URL` 指定站点地址。覆盖真实 GLB 加载、两档精度、延迟下载、缓存、拆解、材质、线框、亮暗主题、移动端、空闲停止渲染、导出及失败重试。
